# 🪙 CoinPulse — Monitor de Cotação de Moedas em Tempo Real

O **CoinPulse** é um script utilitário em Python projetado para consultar cotações de moedas globais e criptomoedas em tempo real, emitindo um alerta no terminal caso a moeda atinja um valor limite estipulado pelo usuário.

---

## 🚀 Funcionalidades

- **Consulta em Tempo Real:** Integração com a API da *AwesomeAPI* para obter dados atualizados de compra.
- **Diversidade de Moedas:** Suporte às principais moedas globais (USD, EUR, GBP, JPY, CAD, AUD, CHF) e criptomoedas (BTC, ETH).
- **Sistema de Alerta Customizável:** O usuário define um valor alvo e o sistema informa se é um bom momento para compra.
- **Tratamento de Erros de Entrada:** Validação com `try/except` para prevenir falhas por digitação incorreta de números ou moedas inexistentes.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Requests** (para requisições HTTP e consumo da API)
- **AwesomeAPI** (fonte de dados das cotações)
